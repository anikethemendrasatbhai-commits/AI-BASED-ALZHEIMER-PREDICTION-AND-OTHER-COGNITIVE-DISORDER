# MindCare Assess — GitHub Pages version

A responsive, static educational demo for exploring original cognitive practice activities.

## Files
- `index.html` — page structure and content
- `style.css` — colours, layout and responsive styling
- `app.js` — interactive activities, local history and report download

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload **all three files** (`index.html`, `style.css`, `app.js`) to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

## Important
- This is an independent static redesign. It is not exported from Emergent and does not change the original Emergent project.
- Activities are original educational exercises, not validated clinical tests. They cannot diagnose or rule out Alzheimer’s disease, dementia, or another condition.
- MoCA, MMSE and other named instruments are not reproduced here; check the relevant owners’ permission and licensing terms before using them.
- Activity history is stored in the visitor's browser using local storage. No backend, account system or cloud database is included.
